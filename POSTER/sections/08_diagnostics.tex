\begin{mosbox}{7. Topological Diagnostics}

\BodyFont

Computing a coherence score answers only one question:

\[
\boxed{
\text{Is the memory coherent?}
}
\]

When disagreement is detected, a second problem immediately arises:

\[
\boxed{
\text{Where does the inconsistency originate?}
}
\]

MOS addresses this through topological diagnostics.

Rather than treating inconsistency as a single scalar quantity, the
framework identifies the simplices responsible for incompatible local
assignments and analyzes their surrounding topological structure.

\end{mosbox}

%% LOCALIZATION
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{mosbox}{Discord Localization}

\BodyFont

The coherence functional identifies the presence of inconsistency.

Local diagnostic procedures determine the simplices whose restriction maps
contribute most strongly to the disagreement energy.

These regions become natural candidates for

\begin{itemize}

\item refinement,

\item correction,

\item semantic revision,

\item structural expansion.

\end{itemize}

Rather than rebuilding the entire knowledge structure, MOS attempts to
localize disagreement before modifying the underlying complex.

\end{mosbox}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
%% TOPOLOGICAL INVARIANTS
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{mosbox}{Topological Invariants}

\BodyFont

Once problematic regions have been identified, global topological
properties provide additional structural information.

Representative invariants include

\[
\boxed{
b_0
}
\]

(number of connected components)

\vspace{2mm}

and

\[
\boxed{
H^{1}(C,\mathcal F)
}
\]

which detects non-trivial compatibility obstructions within the sheaf.

These quantities distinguish isolated local disagreement from genuine
global structural inconsistency.

\end{mosbox}

\begin{highlightbox}

\SectionTitle{Interpretation}

\BodyFont

Diagnostics transform coherence from a passive measurement into an active
verification procedure.

\[
\boxed{
\text{Measure}
\rightarrow
\text{Locate}
\rightarrow
\text{Analyze}
\rightarrow
\text{Repair}
}
\]

The objective is not only to detect inconsistency but also to determine
its geometric origin within the underlying simplicial structure.

\end{highlightbox}

\begin{remarkbox}

\BodyFont

The diagnostic procedures presented here are intended as mathematical
tools for structural verification.

Their implementation within a complete cognitive architecture remains
future work.

The present framework establishes the mathematical quantities and
topological invariants upon which such procedures can be constructed.

\end{remarkbox}
