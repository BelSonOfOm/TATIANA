(Phase 0 invariant, Phase I kill-tests, Phase II Spec A extension, Phase III co-allocation vs.
separation, Phase IV encoder/verification-lift, Phase V resolutions, Phase VI reproduction) — not
by the date it was written.

Each file states, at the top:
- which section of `DOCS/MATH_TOOLBOX.md` or `DOCS/TATIANA_V1_IDENTITY_MAP.md` it extends, reopens,
  or supersedes, and why
- its current epistemic tag(s)
- the falsifier, written before any implementation in `../EXPERIMENTS/` that tests it
