# TATIANA-V2/DOCS

Working document set for V2. Everything here except `LOGBOOK_V2.md` is inherited from the V0
record and is **read-only reference** — corrections go in `LOGBOOK_V2.md` or in the book, never by
silently editing an inherited document, because several of them are cited by the book as the record
of what was once believed.

## What is here, and why

| document | role in V2 | status |
|---|---|---|
| `LOGBOOK_V2.md` | V2's own append-as-you-go decision record | **live** |
| `TATIANA_V1_IDENTITY_MAP.md` | **the binding identity document.** Everything V2 does is answerable to it | live authority |
| `MATH_TOOLBOX.md` | complete inventory of what V0 proved, measured, killed — the founding record | reference |
| `SPEC_GROWTH_ADDRESS_AND_DYNAMICS.md` | Spec A's specification; the growth-address instrument | reference, partly superseded (see identity map §9.2) |
| `DERIVATION_MDL_GROWTH_LAW.md` | Construction 7, the maintenance cost | reference |
| `MEMORY_MODEL_TWO_COMPLEX.md` | the 𝕂/W split and the sheaf adjunction | reference |
| `AUDIT_SCRUTINY_AND_BOOK.md` | the F1–F14 audit findings; the book's epistemic-tag discipline descends from it, and Appendices B and C are built on it | reference |

| `PRIOR_ART_AND_THE_REPLAN.md` | what is not novel and must be cited rather than claimed | reference |

| `THE_GENERATIVE_THOUGHT_MODEL.md`, `WHY_A_MODEL_OF_COGNITION.md` | motivation and the generative-process pivot | reference |

## Deliberately not copied

Left in the repo-root `DOCS/` because they are V0-implementation-specific or fully condensed
elsewhere. Named here so the decision is visible and reversible:

- `TATIANA_LOGBOOK.md` — V0's logbook. Stays in place; `LOGBOOK_V2.md` continues it rather than
  replacing it, and the book cites the original.
- `SPEC_P0_RETRIEVAL_FIX.md`, `SPEC_P1_TO_P4_PROTOTYPE.md`, `BUDGET_AND_TEST_PLAN.md` — V0 engine
  specs and LLM budget planning. The architecture they specify is retired.
- `THE_RETRIEVAL_PROBLEM.md`, `THE_COVER_QUESTION.md` — the retrieval and cover-detection sagas.
  Condensed with all their numbers and methodology lessons into `MATH_TOOLBOX.md` Parts V and VI.
  Copy them here if the detailed run-by-run record is ever needed.
- `MOS_JUSTIFICATION_AND_MEMORY_1.md` — the K₀/Jordan–Hölder memory schema, dropped (both candidate
  categories fail, for opposite reasons — `MATH_TOOLBOX.md` II.1).
- The `.tex` files and PDFs (`TATIANA_Mathematical_Description.tex`, `cognitive_state_space.tex`,
  and the various drafts) — superseded by `../tatiana-book/`.
